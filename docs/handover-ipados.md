## What Inkpad is

A quiet, distraction-free Markdown editor. Read `README.md` first (features, shortcuts, licences),
then `src/prefs.rs` (every user setting and its default) and the scripted self-test in
`src/main.rs` (`fn selftest`), which is the closest thing to a behavioural specification: typing,
selection replacement, undo/redo, the unsaved-changes guard, stale results.

Features the iPad version must reproduce to be the same product:

- The page is the whole window; a 66-character measure, centred; margins do not move when the
  text size changes.
- Three fonts: IBM Plex Mono, IBM Plex Sans, Literata (bundled, OFL). Lato Light for dialogs.
- Light and dark themes (`src/palette.rs`), size and line-height settings.
- **Spotlight**: dims everything except the current paragraph or sentence (`src/highlight.rs`,
  `sentence_at`). **Anchor**: keeps the caret line at a fixed height (typewriter scrolling).
- Markdown highlighting with fenced-code state per line (`src/highlight.rs`, with tests that
  double as a spec, including adversarial inputs that must stay linear).
- Typing sounds: one short sample per key press, two sets (Soft, Keyboard), per-key kinds
  (character, Enter, backspace), volume. Samples in `assets/sounds/` (CC0, see its README).
- Background music: six bundled loops in `assets/music/` (CC0, generated by the author, about
  18 MB) and five generated soundscapes (`src/music.rs`: Focus drone, Rainfall, Cricket night,
  Night train, Open window), with fades between layers; music never starts automatically;
  volume remembered.
- Welcome dialog on first run with "Don't show again"; Appearance, Sound and music, About
  dialogs; About shows version, build number, licences and the GitHub link.
- Document safety: unsaved-changes guard on close/New/Open with Save / Don't save / Cancel
  (Enter / D / Escape); "Don't save" covers only the exact revision it was answered for; saves
  are atomic and never refused; a 20 MiB document limit enforced on every growing edit and on
  open (inclusive); recent files list (8 entries).
- Word, character and sentence statistics (`src/stats.rs`).
- Frosted glass (Linux: Wayland blur). On iPad the equivalent is `UIVisualEffectView`.

## What is portable and what is not

The Rust code is 7.4k lines. By module:

| Module | iPadOS | Notes |
|---|---|---|
| `highlight.rs` | reuse | Pure. Markdown spans, fence state, spotlight ranges. Keep its tests. |
| `stats.rs`, `palette.rs`, `dsp.rs` | reuse | Pure. |
| `history.rs` | reuse | Pure undo/redo with coalescing and budgets; uses `std::time::Instant`. |
| `music.rs` | reuse the generators and `FileSource` | Pure DSP plus symphonia decoding on a worker thread; feed its `fill()` from an `AVAudioSourceNode`. |
| `sound.rs` | reuse the mixer, replace the device | The mixer thread and `Layer` fades are portable; the ALSA device layer (`libloading`) is Linux-only. On iPad, pull 5 ms blocks from the mixer inside an `AVAudioSourceNode` render callback. |
| `prefs.rs`, `recent.rs` | reuse the schema | Key = value file; paths differ (use the app container / `UserDefaults`). |
| `atomic.rs` | optional | Exclusive temp + rename works on iOS, but documents should go through `UIDocument` / the document picker for iCloud and Files integration. |
| `main.rs`, `editor/` | rewrite | iced UI and a vendored iced text editor. iced does not target iOS/iPadOS; do not try to run it there. |
| `frost.rs` | replace | Wayland-only. |

Recommended architecture: a **native SwiftUI/UIKit app** with the text view on `UITextView`
(TextKit 2) and a **Rust core** (`highlight`, `stats`, `history`, `music`, `dsp`, the mixer) built
as a static library for `aarch64-apple-ios` and `aarch64-apple-ios-sim`, bridged with **UniFFI**
(preferred) or cbindgen. The Rust side stays `no_std`-free but must avoid Linux-only crates. If
PMO wants the core as a published crate in this repository, ask Ink; Ink will split it so both
apps share one source.

## Assets and licences (all redistributable, nothing else may be used)

- Code: MIT (`LICENSE`). iced's licence text in `packaging/LICENSE-iced.txt`.
- Fonts: `assets/fonts/` with their OFL texts and `README.md` (upstream static files, SHA-256
  provenance). Use them unmodified; do not generate instances (OFL Reserved Font Names).
- Sounds: `assets/sounds/{soft,keyboard}` CC0 by unicaegames, credit in `assets/sounds/README.md`.
- Music: `assets/music/*.ogg` CC0 by the author (Lyria-generated). Convert to AAC/CAF for iPad.
- Icon: `assets/inkpad-icon-4a.svg` (plus `icon-256.png`, `icon-512.png`).
- **Never** use the old Envato-licensed recordings or any synthesised keystroke sounds that were
  rejected; they are not in the repository and must not come back.
- Never commit API keys; the user's OpenRouter key lives outside any repository.

## Mac Mini setup (PMO's checklist)

1. Xcode with the iOS/iPadOS SDK and simulators; `xcode-select --install`.
2. `rustup` with targets `aarch64-apple-ios` and `aarch64-apple-ios-sim`; `cargo install uniffi-bindgen-cli`
   (or use uniffi as a build dependency); `cargo-lipo` is not needed with modern Xcode (xcframework).
3. `gh` CLI authenticated as 50hoursaweek; `git clone https://github.com/50hoursaweek/inkpad -b v0.1.6`
   for reference only.
4. A new repository for the port, folders like `~/Projects/inkpad-ipados/{InkpadCore (Rust), Inkpad (Xcode)}`.
5. Apple Developer account for TestFlight and the App Store: the user's decision; ask before
   spending anything.
