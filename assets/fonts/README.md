# Fonts

All fonts are under the SIL Open Font License 1.1; each licence file is alongside.

- **IBM Plex Mono** and **IBM Plex Sans** (IBM), the editor's Mono and Sans faces.
  Static Regular, Bold, Italic and Bold Italic instances made from the Google Fonts
  files with fontTools (`wdth` 100 for Sans).
- **Literata** (TypeTogether for Google Fonts), the editor's Serif face. Static instances
  at optical size 18 (`opsz` 18) and weights 400 and 700.
- **Lato Light** (Łukasz Dziedzic), used for the menu and dialogs.
