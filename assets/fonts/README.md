# Fonts

All fonts are under the SIL Open Font License 1.1; each licence file is alongside.
Every file is an unmodified upstream release, so no Reserved Font Name is affected.

- **IBM Plex Mono** and **IBM Plex Sans** (IBM, Reserved Font Name "Plex"): the editor's
  Mono and Sans faces. Static Regular, Bold, Italic and Bold Italic files from the IBM Plex
  repository (`packages/plex-*/fonts/complete/ttf`).
- **Literata** (TypeTogether for Google Fonts): the editor's Serif face. Static files from
  the Literata repository (`fonts/ttf`).
- **Lato Light** (Łukasz Dziedzic), used for the menu and dialogs, from Google Fonts.
